## 사양서에 없어서 위험했던 것
- K26: 지체보상 조항이 없다 — 재무팀(계약서에서 따로 확인). 예비·최종 검수(FAC) 조건이 없다. 목차엔 "3. 검수"와 "7. 사후관리"가 있는데 본문이 없다 — CS팀·재무팀. 장비수명·스페어 공급 기간이 없다 — CS팀·구매팀.

## 묶음 전체에서 눈에 띈 점 (3~6줄)
- 기아 국내 사양서는 2021~2026 사이 같은 틀(공사개요 → 공통 → 기계 → 전기 → 티칭 → 업무 → 제출서류 → FMEA/WOW/안전규정 첨부)을 계속 쓴다. 다만 같은 문서 안에서 숫자가 어긋나는 경우가 5/7(칼라 수·PLC 기종·에어압·보증 기산점·양산대응 기간)이라, '문서 안 불일치 검출'을 부서별 확인에 넣을 가치가 크다.
