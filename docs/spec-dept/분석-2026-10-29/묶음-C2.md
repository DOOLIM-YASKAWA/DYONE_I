## 부서별 확인·주의 사항

### 도장영업팀 (sales.paint)
- **인도조건과 관세 부담이 건마다 다름** — 7/7 · 근거: KaGA p3 "D.D.P (Delivery Duty Paid)", SA-PLA p4 "DDU (Delivered Duty Unpaid)", HMI-P11 p2 "INCOTERMS : CIF Chennai Port", HMMI19 p5 "CIF (항만: 탄중프리옥)" · DDP는 미국 관세·통관까지 우리 부담이라 견적 차이가 큼. KIN은 p2 "납기 (FOB)"와 같은 쪽 "설비인도조건 : CIF"가 한 문서 안에서 서로 다름 → 견적 전 확정 필요(비용)
- **인허가 전부를 공급사가 진행** — 3/7 · 근거: KaGA p3 "obliged to proceed with all licenses", HMMI19 p21 "모든 제반 허가에 대하여 공급업체가 진행", HMMI24 p10 "comply with Indonesia Laws & Regulation" · 현지 인허가 비용·일정을 우리가 지는 구조. 지금 `permit` 키워드(PSM·인허가)로는 영어 3건 중 0건 잡힘(비용·일정)
- **고객 공급 범위(유틸리티·바디·기초 보강)의 경계** — 6/7 · 근거: SA-PLA p3 "SA Scope | 1 | 1st utility", SA-PLA p20 "HMC will supply the basic reinforcement", HMMI19 p6 "설비메인 판넬까지 전기 공급", KaGA p2 "KIA supply scope" · 경계 밖(추가 보강, 메인 판넬 이후 배선)은 전부 우리 몫(비용)
- **사양 차이 미제출 시 고객 사양에 동의한 것으로 간주** — 3/7 · 근거: KIN p23 "동의한것으로간주한다", SA-PLA p25 "HMC's specifications will get higher priority", HMMI19 p22 "RED MARK하여 제출" · 견적 단계에서 차이 표를 안 내면 나중에 모두 무상 대응(비용)
- **고객이 요구하면 하드웨어 추가 없는 수정은 무조건 수용** — 1/7 · 근거: SA-PLA p21 "supplier should accept it" · 무상 SW 수정 범위가 정해지지 않음(공수)
- **SOP·셧다운이 짧고 여러 해에 걸침** — 5/7 · 근거: HMI-P11 p3 "Shutdown: 7+1 days"(2027~2033 매년 5월), HMMI24 p5 "Pre-installation : '24.10/26~11/3", HMMI24 p10 "SOP date | 1st of April 2025" · 7년 연속 계약은 물가·로봇 모델 단종 위험, 8일 셧다운은 공정 손실 위험(일정)
- **스페어·공구·소모품 수량이 사양서에 박혀 있음** — 6/7 · 근거: HMMI24 p10 "Robot Jacket | 1 Robot = 5EA", SA-PLA p8 "15 covers for each robot arm", HMI-P11 p5 "도장기 Tool - 3Set" · 견적 누락이 잦은 소모품(비용)
- **기존 대비 변경점** — 3/7(교체·개조 건) · 근거: KIN p7 "MH24 단종" → GP25, HMMI24 p6 "Same User Interface with existing robot station" · 기존과 같은 UI·메이커를 요구해 다른 메이커 설비와 맞추는 공수가 생김

- HMI-P11: 보증·검수·지체보상·제출서류·스페어 공급기간 없음(요약본이라 원본 사양서 확보 필요) — 도장영업팀·재무팀·CS팀
- HMI-P11: 엔코더·트래킹·차종 수신 방식 없음, 7년 분할 공사의 물가·로봇 단종 대책 없음 — 소프트웨어팀·구매팀·도장영업팀
- KZ-NET: 공사 범위·일정·상업 조건이 전혀 없는 표준 문서. 본 사양서·업무 분장 별도 확보 필요 — 도장영업팀(attach)·PM팀
- SA-PLA: 지체보상 조항 없음, DI water·세정 유틸리티 없음, 도료 점도 없음("provided in detail later") — 재무팀·호남영남지사·도장공정실
- SA-PLA: 스페어 범위는 "Full sparepart list with unit price"를 견적과 함께 내라고만 하고 포함 수량은 없음 — 구매팀·CS팀
- HMMI24: 지체보상·장비수명·스페어 공급기간 없음, 품질 기준이 "HMMI expectation/standard"로 수치 없음 — 재무팀·CS팀·어플리케이션팀
- HMMI24: 에어 압력은 "5.5~6 bar at the end point"만 있고 오프너·7축 레일 에어 소요량 계산 주체 없음 — 호남영남지사·설계팀
- KIN: 지체보상·최종검수(가동률) 조건·장비수명 없음, 인도조건이 FOB(p2 납기)와 CIF(p2 범위표)로 엇갈림 — 재무팀·도장영업팀·CS팀
- KIN: 엔코더·트래킹·인터록 상세 없음(기존 라인 증설인데 기존 PLC 연동 범위 불명) — 소프트웨어팀
- KaGA: 설치·셧다운 기간 없음(DDP 완료일 2024.01.07만), 스페어 "Supply scope / Warehousing" 칸이 비어 있음, 기존 비전 메이커(VMT·ISRA·Favis) 개조 협조 범위 없음 — PM팀·구매팀·자동화영업팀
- HMMI19: 공통사양이라 로봇 공정 세부(엔코더·도장기·막두께)는 별권(Ⅴ-2) 의존 — 부서 확인 시 별권 확보 필요(도장영업팀 attach)

## 묶음 전체에서 눈에 띈 점
- 영어 사양서(SA-PLA·HMMI24·KaGA)에서 지금 키워드가 대거 빠진다: 보증(Warranty)·수명(Life time)·교육(Training)·방폭(Explosion-proof)·반입(forklift)·차종 인식(barcode/identification)이 영어로만 쓰여 한국어 키워드로는 0건이다. 오타(Groundnig·Accpetable·Priliminary)와 단위 글자(㎏) 차이도 놓치는 원인이다.
- KIN처럼 한국어 PDF가 띄어쓰기 없이 추출된 경우("라인중단", "자재의운반", "OP와보전별도교육")가 많아 `\s*`를 넣지 않은 키워드는 놓친다.
- 해외 건의 비용 위험은 상업 조건보다 '현장 부대 의무'에 몰려 있다: 하역 장비, 시험 바디 운송, 현장 사무실·화장실, 통역·코디네이터, 아랍어·인니어 문서, 교대당 안전관리자 2명, 스탠바이 무기한 연장.
- 지체보상은 7건 중 2건만 있고 비율도 0.01%(HMMI19)와 0.1%(KaGA)로 10배 차이. 보증 기점도 SOP·FAC·시운전 후·양산 후로 제각각이라 '상업 조건' 장을 따로 두자는 기존 제안이 맞다.
- 고객 네트워크 표준(KZ-NET)은 IP 대역(140.30~39.X.X, 192.168 금지)·이중화·관리형 스위치를 강제한다. 해외 신공장 건에서는 사양서 본문에 없더라도 이 표준 문서를 따로 요청해야 한다.
- 개조·교체 건(HMI-P11·HMMI24·KIN·KaGA)은 "기존과 동일"(UI·메이커·필터·피팅) 요구가 많아 기존 설비 현황 확보가 견적의 전제다.
