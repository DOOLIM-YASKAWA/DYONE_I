## 자료에서 확인한 전제
- R&R: 사양서 접수는 영업, '사양 정리 SHEET'는 PM이 작성(2014·2020 프로세스 문서). 부서 전달은 영업 → PM → 각 부서 흐름.
- 하계 이슈 66건 중 1위는 설계·도면 간섭(19건, 28.8%). 2026 프로젝트의 48%가 로봇 입고(장납기) 이슈.
- 모듈라 펀치·OLT 트러블의 대부분(튜빙·피팅·케이블 고정)은 조립 품질 문제라 사양서로 막을 수 없음 → 부서 요약에서 제외.
- 기존 양식: `SM 프로세스 정리.xlsx`에 사양정리 양식 + 현장체크 시트(약 30항목) 있음 → 부서 요약의 기준 틀로 쓸 수 있음.

## 사양정리 초안에 반영할 것 (제안)
1. 행·기타 사항마다 '받는 부서' 꼬리표 → 부서별 요약 장 자동 생성(위 표가 기준).
2. 사양서에 **없어서** 확인이 필요한 것도 부서별로 띄우기:
   - 에어 실측값, 엔코더 공급 주체, L/S 위치
   - 스페어 범위, 품질 기준, 반입로
   - 사고가 많았던 항목은 사양서에 없으면 "확인 필요"로.
3. '기존 대비 변경점'(교체 공사) 칸 추가: PCF→DCM 같은 변경 미공지 사고 방지.
4. 부서 이름·담당 범위는 그룹웨어 조직 기준 추정이 섞여 있음 → 각 부서 확인 필요(CS팀, 구매팀, 도장공정실 역할).
