# ERP(NEOE)로 본 부서별 업무 (2026-10-28, dylab 읽기 전용 조회)

## 조회 방법
- 계정 dylab으로 접속했다. db_datareader·db_datawriter·db_owner 역할은 모두 0이다.
- SELECT만 실행했고, 모든 조회에 `WITH(NOLOCK)`과 READ UNCOMMITTED를 걸었다.
- 금액은 옮기지 않았다. 건수와 항목 구성만 적었다.
- 사용한 테이블:
  - 실행예산 원가 구조: `WC_B_COLLBUDGET`
  - 발주: `PU_POH`, `PU_POL`
  - 구매품의: `PU_APPH`
  - 품목과 분류: `MA_PITEM`, `MA_CODEDTL`
  - 직원과 부서: `MA_EMP`, `MA_DEPT`

**사양서와의 연결**
- 사양서의 일정·스탠바이·교육 조항은 '공수관리'의 단계×역할 공수로 바로 이어진다.
- 설비 조항(로봇·도장기·CCV·FGP)은 '공정별 설비' 항목으로 바로 이어진다.
- 그래서 사양정리 행마다 실행예산 항목과 부서를 붙이면, 영업 견적·실행예산·부서 요약이 같은 틀로 맞는다.
