# 사양서 부서별 분석 (2026-10-29)

고객 사양서를 부서(역할)마다 무엇을 확인해야 하는지 기준으로 정밀하게 읽고 정리한 문서다.
부서 담당자와 영업이 견적·착수 전에 읽도록 썼다.

| **합계** | | **53** | 국내 27 / 해외 14 / 일반산업 12 |

- **건수 기준은 53건이다.** 요청서에는 54건이라고 되어 있지만, 각 묶음의 '읽은 사양서' 수를 더하면 7+7+7+6+7+7+14 = 55건이고, D 묶음에서 사양서가 아닌 2건(D4 테이프 기술자료, D9 자사 실행예산 BOM)을 빼면 53건이다. 이 문서의 빈도는 모두 `n/53`이다.
- B2의 HMMC(현대 체코)는 해외 건이지만 묶음을 따라 '국내 27'에 넣어 셌다.
- D 묶음 결과는 원래 `n/14`로 적혀 있다. 이 문서에서는 12건 기준으로 바꿨다. 근거에 D4·D9가 들어 있으면 그만큼 뺐고, 아니면 숫자를 그대로 두되 12를 넘지 않게 했다.
- 같은 내용이 여러 묶음에 있으면 묶음별 건수를 더했다. 묶음마다 세는 기준이 조금 달라서 ±1~2건 차이는 있을 수 있다.
- 근거는 모두 묶음 결과 파일에 있는 것만 썼다. 새로 추측한 내용은 없다.

### 1-3. 읽는 법

- **빈도** `n/53` = 53건 중 그 조항이 있던 사양서 수. 괄호 안은 `국내/해외/일반산업` 순서 (분모 27/14/12).
- **근거** `A1 광주2후드 p8` = 묶음 A1의 '광주2후드' 사양서 8쪽. 쪽 번호는 글 파일의 `[pN]` 기준이다.
- **역할 키**(`sales.paint` 등)는 코드 `DeptChecklist.cs`의 키다. 부서 이름은 `spec-dept-orgchart.md`를 따른다.
- **지금 적중률**은 전수 233건에서 지금 키워드가 근거를 찾은 비율이다. 낮다고 사양서에 없는 것이 아니다. 키워드가 좁아서 못 찾은 경우가 많다(아래 각 장에 적음).
- 코드에 옮길 키워드·새 항목은 따로 정리했다 → `분석-2026-10-29/키워드·항목 반영안.md`

## 4. 고객 유형별 차이

| 구분 | 특징 | 확인 요령 |
|---|---|---|
| **국내 완성차 — 기아·현대** (A1·A2·B1 현대·B2 현대) | 2017~2026 같은 구매요구사양서 틀(공사개요→공통→기계→전기→티칭→업무→제출서류→FMEA/WOW/안전규정 별지). 지체·보증·FAC 수치가 사양서에 있는 편. 30분 UPS가 표준. 하기휴무 9일 셧다운. 동의 간주·청소 인원·수주자 부담 조항이 반복. FMEA에 "※두림로봇" 사례가 남아 있다 | 같은 틀이라 조항→부서 규칙이 잘 맞는다. 대신 **문서 안 모순(5/7)과 별지 미확보**를 먼저 본다 |
| **국내 완성차 — GM** (B1 B·C·F, B2 UBS·T2BC·2T) | 영어 SOR 틀. 지체보상·인도조건은 사양서에 없고 계약서(Construction General Terms)에 있다. 대신 비상 파트 금액(1~1.5억), 인허가 비용 일괄, MTBF·MTTR·가동률, 안전 위반 퇴출, AB PLC, 서보 시간 보증, 사이버보안 정책이 있다 | 한글 키워드가 거의 안 걸린다. 영어 키워드 보강 효과가 가장 크다. `CIF`·`FAC`·`LS`·"Maker Standard"·"future spare parts" 오탐으로 적중률이 부풀려져 있다 |
| **해외** (C1·C2, B2 HMMC) | 인도조건 DDP·DDU·DAP·CIF·FOB가 제각각. 번역본(KaSK 영→한, KCN 중→한)이 들어온다. 현지 인증·언어·통역·세금 비용. 비용 위험이 상업 조건보다 **현장 부대 의무**(하역 장비·시험 바디 운송·사무실·화장실·통역·교대당 안전관리자 2명·스탠바이 무기한 연장)에 몰려 있다. 고객 네트워크 표준(IP 대역·이중화)이 있다 | 인증·세금·언어·단위·현장 시설을 한 묶음으로 확인한다. 번역어 사전(저하 모드·강등 모드·시범 교육·송송체·인코더)이 필요하다 |
| **일반산업·기타** (D) | 상업 조건이 극단적이다. 있으면 강하고(지체 0.1%·고의면 상한 초과, 생산손실 배상, 대금 공제·이월, 특허 공동출원, 변경 무상 반영), 없으면 아예 공란이다. '바디·차종·막두께' 대신 '제품 사이즈·재질·성공률·정확도·cpm'을 쓴다. 입찰 조건이 사양서 안에 있다. 지정이 모델명·품번 단위다. 사양서가 아닌 파일이 섞여 있다 | 전수 적중률이 일반산업에서 낮은 이유는 표현 차이와 원래 없음이 섞인 것이다. **"없음 → 계약서·공통사양서 확인"**을 띄우는 것이 더 중요하다 |

전수 집계에서 차이가 큰 항목(국내 → 일반산업): `education.fac` 60% → 11%, `pm.lineloss` 50% → 14%, `modular.fmea` 44% → 5%, `paint.lab.labtest` 34% → 5%, `teach.degrade` 47% → 8%. 정밀 읽기로 보면 일반산업은 실제로 이 조항이 드물거나(FMEA·LAB), 표현이 달랐다('10分 이상 라인중단', '손배상', 'Back Up 가능토록').
